游戏机制详解

全面掌握 Forsaken 的核心游戏系统

🕐 比赛流程

准备阶段（Intermission）

每局比赛开始前，玩家会进入准备阶段。在此期间：

  • 玩家可以自由探索准备区域
  • 随机选择本局比赛的杀手和幸存者
  • 随机选择比赛地图
  • 玩家可以购买游戏通行证（Gamepasses）

标准回合（Standard Round）

比赛正式开始后：

  • 幸存者需要在倒计时结束前完成地图目标或存活下来
  • 杀手需要猎杀所有幸存者
  • 如果所有幸存者被消灭，杀手获胜
  • 如果倒计时结束仍有幸存者存活，幸存者获胜
  • 完成所有地图目标可以加速倒计时

回合时间

  • ≤4人：3分钟
  • 5人：3分30秒
  • ≥6人：4分钟

最后一人（Last Man Standing - LMS）

当仅剩最后一名幸存者时自动触发，这不是独立模式而是标准模式的阶段：

  • 倒计时自动改为1分14秒
  • 播放LMS专属音乐
  • 最后幸存者和杀手互相高亮6秒（无视Undetectable隐身效果）
  • 完成目标不再减少倒计时
  • 不会增加任何血量上限，幸存者保持原有生命值
  • 如果幸存者与杀手有特殊关系（如007n7 vs c00lkidd、Jane Doe vs John Doe等），倒计时为1分30秒（Jane Doe vs John Doe为1分40秒）并播放特殊主题音乐
  • 部分杀手皮肤可自定义LMS主题，略微改变计时器时间

⚡ 耐力系统（Stamina）

💡 耐力管理是游戏的核心！合理使用耐力是在追杀中存活的关键。

基础数值

属性 数值
最大耐力100
每秒恢复20
跑步消耗10/秒
耐力耗尽无法跑步

耐力管理技巧

  • 不要一直按住跑步键，在安全区域步行保存耐力
  • 在转弯或障碍物后短暂停顿恢复耐力
  • 预判杀手位置，提前规划逃跑路线
  • 利用地形和障碍物减少需要的跑步距离
  • 注意耐力条，保持至少 30% 的耐力储备

🎯 目标系统（Objectives）

目标类型

当前游戏中只有1种主要目标：

  • 发电机（Generators）：每张地图5台。幸存者需要完成4个小游戏（连接相同颜色/数字的节点）。完成1个小游戏减少3秒倒计时，4个共减少12秒。完成1台发电机获得5$、15EXP、0.5 Malice

完成全部5台发电机共减少60秒倒计时。

目标完成策略

  • 优先完成远离杀手的目标
  • 与队友分工合作，不要扎堆做同一个目标
  • 做目标时保持警觉，注意杀手的声音和恐怖范围
  • 如果杀手靠近，果断放弃目标逃跑
  • 利用做目标的时间观察周围地形

🔄 状态效果（Status Effects）

负面效果（Debuffs）

效果 说明
流血（Bleeding）持续损失生命值，会留下血迹让杀手追踪
减速（Slowness）降低移动速度，更容易被追上
虚弱（Weakness）降低伤害输出或治疗效果
无助（Helpless）无法使用技能或特殊能力
恐惧（Fear）影响视野或产生幻觉效果

正面效果（Buffs）

效果 说明
加速（Speed）提高移动速度，等级越高效果越强
抗性（Resistance）减少受到的伤害或控制时间
隐身（Invisible）使杀手难以发现你
治疗（Healing）持续恢复生命值

🏆 玩家等级与经验

经验值（EXP）获取

  • 存活时间越长，获得的经验越多
  • 完成地图目标获得经验奖励
  • 使用角色技能成功对抗杀手获得经验
  • 每局比赛结束后根据表现结算经验

等级奖励

  • 提升等级解锁新的角色
  • 获得角色专属皮肤
  • 解锁成就和里程碑奖励

🩸 恶意值系统（Malice）

获取与机制

  • Malice最高的玩家会被选为杀手
  • 完成1台发电机获得0.5 Malice
  • 击杀幸存者获得Malice
  • 使用技能成功对抗对手获得Malice
  • 想当杀手需要积累Malice

🎮 游戏模式

Standard（标准模式）

默认且唯一公开服务器可玩的游戏模式。

  • 1名杀手对抗多名幸存者
  • 杀手目标：在倒计时结束前击杀所有幸存者
  • 幸存者目标：存活至倒计时归零或完成所有目标
  • 击杀幸存者+40秒回合时间
  • 完成一个目标（发电机）减少12秒，全部5个完成共减少60秒
  • 仅剩1人时进入Last Man Standing阶段

Extermination（灭绝模式）

仅限私服的专属模式，需要通过指令面板选择。当前已损坏，无法游玩。

  • 所有幸存者变为SWAT Officer，持枪对抗杀手
  • Type 1：150HP，闪光弹，突击步枪+医疗包
  • Type 2：100HP，闪光弹，突击步枪+医疗包
  • Type 3：100HP，闪光弹，突击步枪
  • Type 4：75HP，闪光弹，格洛克+医疗包
  • 幸存者有额外任务击杀杀手，但不是获胜必要条件

Double Trouble（双重麻烦）

即将推出，尚未实装。预计两名杀手同时对抗幸存者，目标与标准模式相同，但双杀手大幅改变玩法。

Baby Gamemode（婴儿模式）

即将推出，尚未实装。预计为私服专属模式，所有角色变为婴儿形态，属性被削弱（Chance始终携带已装弹的枪，c00lkidd为缩小版模型）。

🎫 游戏通行证（Gamepasses）

游戏内可以购买各种通行证来增强体验：

  • 额外生命：获得额外的复活机会
  • 经验加成：提升获得的经验值
  • 专属角色：解锁特殊角色
  • 皮肤包：获取角色专属外观

👻 恐怖范围（Terror Radius）

每个杀手都有一个恐怖范围，当幸存者进入这个范围时：

  • 会听到心跳声，距离越近声音越大
  • 屏幕可能出现视觉效果提示
  • 某些杀手有更大的恐怖范围，更难察觉
  • 部分杀手技能可以缩小或隐藏恐怖范围

💡 技巧：学会听心跳声判断杀手距离和方向，这是躲避杀手的关键技能。

💰 游戏内货币

通过游戏可以获得游戏内货币（$）：

  • 完成目标获得货币奖励
  • 对杀手造成伤害或控制获得货币
  • 存活到比赛结束获得结算货币
  • 货币可用于购买角色和皮肤
