团队打团攻略

幸存者如何配合对抗杀手，最大化团队存活率

👥 团队阵容搭配

理想阵容结构

  • 1名哨兵：负责打断杀手追击、保护队友（Shedletsky/Guest 1337/Jane Doe/Two Time）
  • 1-2名辅助：提供治疗/护盾/建筑支援（Elliot/Builderman/Dusekkar/Taph）
  • 1-2名生存专家：负责做目标和吸引火力（Noob/007n7/Veeronica）

推荐阵容示例

  • 均衡型：Shedletsky + Elliot + Builderman + Noob
  • 进攻型：Jane Doe + Two Time + Elliot + Veeronica
  • 防守型：Guest 1337 + Builderman + Taph + Noob
  • 快速目标型：Shedletsky + Veeronica + 007n7 + Elliot

避免的组合

  • 多个Elliot：治疗量递减严重（每个减少12%，最低80%）
  • 多个Builderman：建筑重叠浪费，且缺乏追击辅助
  • 纯生存专家阵容：缺乏团队保护能力

⚔️ 打团战术详解

救援战术：队友被追时

哨兵救援

  • Shedletsky：主动上前Slash杀手，3秒眩晕足够队友脱离。命中后获得0.575秒抗性II可硬吃一击
  • Guest 1337：Charge击退杀手，Block格挡后续攻击
  • Jane Doe：投掷水晶施加Resonance，然后Hatchet眩晕。注意自身HP仅60，保持距离
  • Two Time：趁杀手注意力在被追队友身上时，蹲伏绕后背刺（3.5秒眩晕）
  • Chance：Coin Flip正面获得充能后One Shot射击杀手（2-4秒眩晕+击退5码）。近距离眩晕4秒收益更高。注意：Weakness叠加时One Shot爆炸对自身25伤害可能致命。Hat Fix清除Weakness（60秒冷却）。v4.0.0后爆炸6×6×6范围眩晕5秒，为队友创造窗口

辅助救援

  • Elliot：在被追队友路线上提前放置披萨，提供持续治疗
  • Builderman：放置哨戒炮干扰杀手路径，补给站提供躲避治疗点
  • Dusekkar：Spawn Protection为被追队友施加护盾
  • Taph：在杀手追击路线设置绊线和地雷

生存专家自救

  • Noob：Ghostburger隐身10秒切断追踪，Slateskin承受伤害
  • 007n7：Clone克隆体阻挡杀手，为队友和自己创造逃生窗口
  • Veeronica：Bumper击退杀手，Phase穿透获得4秒速度+抗性窗口

围堵战术：多人合作击杀杀手

在Extermination模式或特定情况下，幸存者可以尝试围堵杀手：

  • 哨兵冲锋：Shedletsky/Two Time/Guest 1337从不同方向接近
  • 辅助控场：Taph设置绊线封锁逃跑路线，Builderman放置哨戒炮限制移动
  • 生存专家补位：Veeronica从侧翼Bumper，Noob用Slateskin承受伤害
  • 注意：标准模式下幸存者目标是存活而非击杀杀手

对抗各杀手的打团策略

对抗Slasher

  • 避免被Raging Pace无效化：Slasher可用Raging Pace无效化Dusekkar的Plasma Beam、Taph的绊线/地雷Helpless、Guest 1337的Charge、Veeronica的Bumper。不要在其Raging Pace激活时使用这些技能
  • Behead警告：Slasher的Behead可锁定技能动作（Noob喝可乐、Veeronica滑板）。被追时不要在这些动作中被Behead
  • 007n7克隆体无效：Behead穿透克隆体，克隆体仅对普通攻击有效
  • 团队策略：Slasher小恐怖范围（60码），团队可分散做目标，等其接近再集中打断

对抗Guest 666

  • Manic Fixation速度威胁：30码内任何方向都有10-15%速度加成，团队必须保持30码以上距离
  • Infernal Cry范围伤害：冲击波同时命中多个幸存者+暂时透明效果。被命中时分散站位
  • 滚雪球效应：Bloodhound被动追踪受伤幸存者，Hemorrhage持续120秒。被击伤的队友需要优先治疗
  • 团队策略：Guest 666拥有2500HP，Sentinel眩晕效果有限。优先保护被追队友而非围堵
  • Slateskin免疫：Slateskin幸存者不受Hemorrhage影响，Guest 666无法从他们获得Blood

对抗c00lkidd

  • Walkspeed Override免疫窗口：命中后获得1.5秒眩晕免疫，Sentinel技能在此窗口完全无效。等其技能冷却后再使用打断
  • Pizza Delivery小弟分散：小弟移动速度14追踪幸存者，15HP+Burning 3秒。团队被迫分散，需要协调逃生路线
  • Builderman建筑格挡：建筑可阻挡Walkspeed Override冲刺，是c00lkidd的唯一克制点
  • Corrupt Nature减速：远距离投掷施加Slowness I持续4秒，命中2+幸存者。被减速时队友需要掩护
  • 团队策略：c00lkidd将Sentinels视为"cheaters"，会优先针对哨兵。哨兵需要自我保护和队友掩护

对抗John Doe

  • puddle覆盖战术： puddle最多5个，存在165秒（无限寿命），声音90码。团队需要绕行 puddle区域
  • Unstoppable被动反制：被眩晕时获得Speed I持续2.5秒（每个额外Sentinel+1秒）。眩晕John Doe反而给他加速，需谨慎使用Sentinel技能
  • Corrupt Energy尖刺封锁：27个尖刺存在12秒，幸存者无法攀爬。团队需要寻找替代路线
  • 404 ERROR墙壁：声音200码可听到，幸存者aura暴露6秒。团队听到声音立刻分散
  • 团队策略： puddle声音90码预警，尖刺12秒封锁窗口，404 ERROR 200码极远预警。团队利用声音线索协调移动

对抗Noli

  • Hallucination暴露：任何等级Hallucination都向Noli暴露幸存者aura，团队无法利用掩体隐藏
  • Hallucination III幻象：出现Noli幻象攻击——不要看它！被Noli命中清除所有堆叠
  • Nova大范围爆炸：26码球形hitbox同时命中多个幸存者+Slowness。团队分散避免被一网打尽
  • Void Rush链式追击：rerush窗口2秒可连续追击多个幸存者。Team必须避免站在一起
  • 假目标迷惑：假发电机/假补给站/假力场，完成假发电机有视觉提示。团队需要识别真假目标
  • 团队策略：Builderman建筑可阻挡Void Rush（Taph陷阱不行）。Nova拉力增强，被拉入时调整方向远离队友

对抗Nosferatu

  • Levitation无声威胁：无法通过脚步声预警，唯一无声杀手。团队需要视觉搜索和互相警告
  • Blood Hook QTE：90码+超远射程拉入幸存者，触发QTE。v3.4.1修复spam bug，需要真正反应速度
  • Cataclysm区域控制： puddle持续12秒，踩上获得Bleeding II并被高亮5秒。团队避免进入 puddle区域
  • Hunter's Feast隐身：命中后获得Invisibility V，Nosferatu消失后团队需要警惕重新出现位置
  • Ascension俯冲：蝙蝠形态飞行，俯冲伤害10-35HP递增。v3.6.0增加俯冲着陆指示器，团队看到指示器立刻分散
  • 团队策略：无声杀手无法预警，团队必须保持视觉联系。Blood Hook QTE失败被拉入时队友立刻使用打断技能

对抗1x1x1x1

  • Mass Infection远程威胁：投掷物速度快，预判走位命中。施加Poisoned+Glitched效果干扰视野
  • Glitched I视野干扰：持续5秒，被命中后难以看清杀手位置和投掷物。团队需要语音引导
  • Entanglement拉近：命中将幸存者拉近，获得Speed II持续2.5秒追击窗口。被拉近队友需要队友掩护
  • Rejuvenate The Rotten僵尸：200秒冷却召唤僵尸追踪（30码范围），击杀僵尸的1x1x1x1获得Speed I持续7秒（最多Speed III）。团队优先击杀僵尸减少杀手速度加成
  • Unstable Eye：声音400码半径可听到，极远预警。团队听到声音立刻分散并准备逃生
  • 团队策略：1x1x1x1远程攻击是平坦投掷物，可利用高低地形躲避。Slash命中后视野受干扰5秒需要盲跑

目标保护战术

  • 哨兵在目标点附近巡逻，保护做目标的队友
  • 辅助提前在目标点放置治疗/防御设施
  • 生存专家优先做目标，减少回合时间
  • Builderman可同时放置建筑+做目标节省时间
  • 每个发电机完成减少12秒，5个共减少60秒
  • 完成目标的幸存者获得5$、15EXP、0.5Malice

🤝 角色协同组合

⭐ 强力协同

  • Builderman + Taph：建筑分散杀手注意力使绊线更有效，炸弹中断拆除哨戒炮。最佳防守组合
  • Elliot + 任何哨兵：哨兵打断杀手，Elliot治疗被追队友。持续作战核心
  • Veeronica + Jane Doe：Veeronica高机动性骚扰，Jane Doe远程水晶输出。双骚扰组合
  • Shedletsky + Elliot：经典攻防搭配，Shedletsky前线和Elliot后方治疗
  • 007n7 + Two Time：克隆体掩护Two Time绕背突刺

⚠️ 注意互斥关系

  • Veeronica无法接受Elliot/Builderman的治疗：不要浪费治疗资源在她身上
  • 007n7无法接受Elliot的披萨治疗：被加入黑名单
  • 多个Elliot治疗量递减：队伍只选1个Elliot

💬 团队沟通要点

  • 报告杀手位置（利用Jane Doe的Digital Footprint脚印追踪）
  • 协调技能使用（如Taph设置绊线后通知队友引杀手过来）
  • 分配做目标区域（避免多人同时做同一个目标）
  • 求救信号（被追时通知队友来救援）
  • 杀手技能冷却跟踪（如Shedletsky的Slash、Noob的Ghostburger等）

🎯 打团时机判断

何时应该集结

  • 杀手正在追击关键队友（辅助/做目标者）
  • Last Man Standing阶段（需要保护最后幸存者）
  • 队友技能准备好可以进行有效救援时
  • 地形有利于团队防守（狭窄通道/有掩体区域）

何时应该分散

  • 杀手有范围技能或冲锋技能时
  • 团队已被杀手发现且位置暴露
  • 需要做多个目标时
  • 避免被一网打尽

距离控制原则

  • 队友之间保持适当距离（不要太近以免被范围技能命中）
  • 但也不能太远（无法及时救援）
  • 理想距离：可以看到队友轮廓但不会同时被发现
