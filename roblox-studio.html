🎮 Roblox Studio / Luau 入门

写给自己，也写给刚入坑的你。没废话，能跑就行。

1. 变量与数据类型

Luau 是 Lua 的亲戚，变量不用声明类型，直接local一下就能用。别用全局变量，容易出幺蛾子。

-- 基础数据类型，很直观
local playerName = "UntilBeef"   -- 字符串
local health = 100            -- 数字
local isAlive = true          -- 布尔值
local inventory = {"Sword", "Shield"}  -- 表（后面细讲）

-- 输出到控制台看看
print("玩家名字是:", playerName)
小贴士： 在 Roblox Studio 里按 F9 或 View -> Output 可以打开输出窗口，print 的内容都在那里看。

2. 函数

函数就是把一堆代码打包起来，以后想复用直接调用。Luau 里函数也是一等公民，可以赋值给变量。

-- 定义一个普通函数
local function greetPlayer(name)
    print("你好，" .. name .. "! 欢迎来到我的游戏。")
end

-- 调用它
greetPlayer("UntilBeef")

-- 带返回值的函数
local function calculateDamage(base, multiplier)
    return base * multiplier
end

local damage = calculateDamage(10, 2.5)
print("造成的伤害:", damage)  -- 输出 25
注意： 字符串拼接用 .. 而不是 +。用 + 会报错，别问我怎么知道的。

3. 条件判断

if-else 这一套到哪都差不多，Luau 里 ~= 表示不等于（别写成 !=，那是别的语言）。

local score = 85

if score >= 90 then
    print("优秀！")
elseif score >= 60 then
    print("及格了，还行。")
else
    print("再接再厉吧...")
end

-- 检查布尔值
local hasKey = false
if not hasKey then
    print("你没有钥匙，门打不开。")
end

4. 循环

循环有三种常用写法，for 循环最常用，while 次之。repeat 我基本不用，但你知道有这回事就行。

-- for 循环，从 1 到 5
for i = 1, 5 do
    print("当前数字:", i)
end

-- 遍历数组（ ipairs 按顺序）
local weapons = {"剑", "弓", "法杖"}
for index, value in ipairs(weapons) do
    print(index, ":", value)
end

-- while 循环，记得别把条件写死，不然就无限循环了
local count = 3
while count > 0 do
    print("倒计时:", count)
    count = count - 1
end
小贴士： 遍历字典（键值对）用 pairs，遍历数组用 ipairs。用错了顺序可能会乱，别问我怎么知道的。

5. 表（Table）—— Luau 的核心

表在 Luau 里就是万能容器，数组、字典、对象，全是它。理解表，基本就理解了一半 Luau。

-- 数组
local fruits = {"苹果", "香蕉", "橙子"}
print(fruits[1])  -- 注意：Luau 索引从 1 开始，不是 0！

-- 字典（键值对）
local playerData = {
    name = "UntilBeef",
    level = 42,
    coins = 999
}
print(playerData.name)  -- 用点号访问
print(playerData["level"])  -- 或者中括号，键是字符串时两种都行

-- 混合使用（这就是 Roblox 里常见的配置表写法）
local config = {
    maxPlayers = 10,
    gameModes = {"生存", "竞技", "合作"},
    enablePVP = true
}
重要： Luau 的数组索引从 1 开始！从 1 开始！从 1 开始！习惯了其他语言从 0 开始的朋友，这里会狠狠坑你一次。

6. 事件与连接（Events）

Roblox 开发里到处都是事件，玩家点击、角色死亡、属性变化，全要靠事件监听。Connect 就是你的好朋友。

-- 获取一个部件（Part）
local part = workspace:FindFirstChild("MyPart")

-- 监听点击事件（需要 ClickDetector）
local clickDetector = part:FindFirstChildOfClass("ClickDetector")
if clickDetector then
    clickDetector.MouseClick:Connect(function(player)
        print(player.Name .. " 点击了部件！")
    end)
end

-- 监听属性变化
part:GetPropertyChangedSignal("Position"):Connect(function()
    print("部件位置变了")
end)
小贴士： 事件连接后会一直存在，如果你不需要了记得用变量存起来然后 Disconnect，不然内存泄漏找起来很头疼。

7. 创建和操控实例

用 Instance.new 可以代码里创建部件，不用每次都手动拖。配合循环可以快速生成一堆东西。

-- 创建一个新的 Part
local part = Instance.new("Part")
part.Size = Vector3.new(4, 1, 2)
part.Position = Vector3.new(0, 10, 0)
part.Anchored = true  -- 锚定住，不然会掉下来
part.BrickColor = BrickColor.new("Bright red")
part.Parent = workspace  -- 放进工作区才能看到

-- 批量创建（比如生成一排方块）
for i = 1, 5 do
    local block = Instance.new("Part")
    block.Size = Vector3.new(2, 2, 2)
    block.Position = Vector3.new(i * 3, 5, 0)
    block.Anchored = true
    block.Parent = workspace
end
注意： 设置 Parent 一定要放在最后，因为 Parent 改变时会触发很多内部事件，先设置属性再设 Parent 性能更好。

8. 常用服务（Services）

Roblox 有很多内置服务，用 game:GetService 获取，这是标准写法，别直接 game.Players 那种写法，不规范。

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local TweenService = game:GetService("TweenService")
local RunService = game:GetService("RunService")

-- 玩家加入事件
Players.PlayerAdded:Connect(function(player)
    print(player.Name .. " 加入了游戏！")
end)

-- 每帧运行（用于平滑动画或物理）
RunService.Heartbeat:Connect(function(dt)
    -- dt 是上一帧到现在的时间差（秒）
end)

9. 最后说两句

Luau 其实不难，难的是 Roblox 的 API 生态太庞大，很多时候你不知道哪个服务该干嘛。我的经验是：

  • 遇到不会的，先去 Roblox Creator Hub 搜，官方文档虽然有时候解释得不太人话，但示例代码很有用。
  • print 调试大法永远不过时，哪里不对先 print 出来看看。
  • 别在客户端信任任何数据，外挂想改本地脚本太容易了，重要逻辑放 ServerScript。
  • 善用 ModuleScript，把公共函数抽出来，别每个脚本都复制粘贴一堆重复代码。

写游戏就是不断试错，报错信息仔细看，大部分时候谷歌一下或者去 DevForum 都能找到答案。加油。
